Build a desktop application using Electron and React.

The application should display a collection of documents. A user should be able to open any document, edit its content, and reference another document from within the editor using an @ mention (similar to Notion or Slack).

When the user types @, they should be able to search for another document, select it, and insert a reference. Clicking the inserted reference should navigate to the referenced document.

The implementation details are intentionally left open. I am interested in seeing how you approach the problem, structure the application, and make engineering decisions.

Please spend no more than 4–5 hours on the assignment.

Feel free to use any libraries or AI tools you find helpful. During the follow-up interview, we’ll discuss your design decisions and may ask you to extend the implementation with a small feature.
